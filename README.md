## 本地打开

从根目录 `index.html` 进入项目导航。用户端原型的主文件为
`02_小程序原型/风雪押镖局-四城一碗粥-小程序.html`；各模块的详细使用方式见各自 README。

需要通过本地 HTTP 访问时，在本目录运行：

```sh
python3 -m http.server 8000
```

浏览器访问 `http://localhost:8000/`。这些页面是展示和交互原型；实际门店系统、打印硬件及小程序服务的接入范围见模块文档。

## 文件与备份

仓库保留原目录结构、原始素材、现有 ZIP 和校验文件。下载后请保持目录层级，以保证跨项目资源引用正常。
Git 不记录空目录，因此预留的空目录使用 `.gitkeep` 占位。
