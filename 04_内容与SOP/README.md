## 一行启用公共图标与全局样式

公共资源就绪后，在 [data-adapter.js](js/data-adapter.js) 中把下面一行的 `false` 改成 `true`。

```js
const USE_PUBLIC_RESOURCES = false;
```

同一开关会启用 `PUBLIC_ICON_BASE_PATH = '../00_公共资源/02_交互图标库/'`，并加载 `PUBLIC_THEME_PATH` 指向的 `../00_公共资源/theme.css`。路径相对 `index.html`。图标按适配层原样列出的全部文件名请求，公共 SVG 成功显示前保留同名本地图。公共主题用同名 `:root` 变量覆盖，缺失变量沿用本地主题，布局和打印由 `handbook.css` 管理。

需求标题写 18 张，逐项列出了 19 个文件名。适配层与本地资源覆盖了全部 19 个，含两组双态及四城音符。
