# 四城民谣故事、寻味留声与歌词暗号总库

## 四城共熬一碗粥 · 合奏总览

> 一碗热粥暖皮囊，一首民谣暖魂灵。粥熬百味，歌敬异乡。

腊八寒夜，南昌万寿宫、武汉武昌、西安南门、苏州山塘街四家分舵，合四城风物熬一锅「四海百家福粥」敬街头风雪人，合四城酒客与歌手之声，共谱一首跨越千里的冬夜民谣。

### 第二关 · 两分钟火塘口述与 NFC 逐字稿

**给老谢留一处避风的地方**

唱歌前讲个人，叫老谢。大冰写过他。老谢在街头唱自己写的歌，靠卖专辑接着走。那时候做一张专辑也不体面，歌用网吧的麦克风录，盘一张一张刻。你听着也许有杂声，可那是人家拿自己的手挣出来的东西。今晚靠门的风大，坐那边的朋友往里挪半步。讲到老谢，我想到的就是这个动作。

老谢经过丽江，在大冰的小屋唱过。他愿意卖自己做的唱片，打算靠这点钱走下去。大冰留了个唱歌的地方给他，也尊重他的打算。我喜欢这件事里那个分寸。伸手帮忙很容易变成替别人拿主意，接住人难，接住了还由着他走自己的路更难。吉他还是他的，台上的歌也还是他的。

咱们今晚在西安南门。出了门，风沿着砖拱灌进衣领，手碰上琴弦都有点迟钝。我手边这把老木吉他，是咱们今晚讲这件事用的信物。有人冻得唱不了第二段，就让他把手捂热一会儿。等手能按住和弦，再把那首自己写的歌唱完。现在听一首老歌，等最后一个和弦落下，再把这个信物记到手机里。

- **日常歌单老歌**　《送别》
- **自动核验标准答案**　老木吉他
- **容错同义词**　木吉他、老吉他

### 第二关 · 两分钟火塘口述与 NFC 逐字稿

**给没名气的人搭个台**

今晚这段事从一篇采访讲起。大冰年轻时背过吉他上路，后来手受过伤，弹琴这件事变难了。那个落差，常摸琴的朋友也许知道。一个和弦练到手指自己会走，忽然有一天，它走不过去了。你坐在台下听别人调弦，心里其实跟着拧了一圈。后来他能帮人做的事里，有一件是搭台。

那是面向高校的免费唱聊会。他出钱筹办，把原来在街头唱歌的人带到学校去。一把琴从街边到了台上，唱的人还是那个人。台下却多了许多肯等一首歌唱完的耳朵。大家也许只记得一个活动有多少站。我更愿意记得，有些人以前得在行人过去之前赶快唱到副歌，那一晚有人完整听完了他的第一段。

武昌这头，船一鸣笛，江边走路的人会抬一下头。今晚我们把笛声收进了第一关，接了一口民谣口琴。咱们手边这支口琴就是暗号。等会儿还会有只木匣，可能把另外一座城的声音交到你手上。买没买过那个人的唱片都无妨，拿起票，听完他那十秒。刚好够他把一句唱完整。

- **自动核验标准答案**　民谣口琴
- **容错同义词**　口琴、C调口琴

### 第二关 · 两分钟火塘口述与 NFC 逐字稿

**那晚有人坐下来帮她打鼓**

讲个女孩第一次在小屋唱歌的事。她叫一鸣，在大冰写过的文章里自己回忆过。那时厦门小屋刚开业，人多，她在义务唱歌，心里紧张。你们有谁唱过第一次就知道，试音的时候还能弹，灯一亮，突然不知道前排的人会不会听见自己的手抖。头一回上台容易怕空一拍，怕自己一停，大家以为这一首已经完了。

大冰进了屋，坐下来给她打鼓。他跟在歌里，把听歌的人也带进来。后来他劝她放松，把小屋当家。这是她记下来的事。台下一个人帮你把拍子托住了，你的手还在抖，歌却有地方继续往下走。这样的忙做完，听的人或许只觉得今晚那一段节奏挺稳。唱的人会记很久。下次换个人上台，她大概也知道怎么接那一拍。

今晚咱们坐在万寿宫。门外大戏台檐上若有风，铜铃会响，风一住，铃就歇。里头的节拍还在，你愿意的话就用指头轻敲一下膝盖。第二关记住的是那件帮她把拍子接下去的乐器——手鼓。等会儿米落进陶缸，也有节奏。给隔壁桌先留一点安静，听听第一粒米落下去是什么声。

- **自动核验标准答案**　手鼓
- **容错同义词**　鼓、手打鼓

### 第二关 · 两分钟火塘口述与 NFC 逐字稿

**给回不去的人买张票**

年关前在外头的人，常把两样东西翻来覆去看，一样是手机上的班次，一样是家里来的消息。有时请到了假，票买不到。想说晚两天就回，又不知这个两天得等多久。关于大冰，有件小事见过报。他会在春节前给一部分没买到车票的读者买返乡机票。报道没交代这些人都去了哪儿，今晚我也讲到这张票为止。

一张票放在手上轻，搁在那两天里挺重。你要照着班次请假、回出租屋收好行李，还得想要不要提前告诉家里。有人能搭把手，这几桩小事就能一样一样办下去。我在山塘水边常听到「慢点」两个字，摇橹船靠岸的时候说，过石桥背后一串人也说。已经有人伸手拉了你一把，等下一班船来的时候，也能站稳了等别人上岸。

腊八还没到除夕，今晚的票可以先寄给暂时回不去的人。纸薄，铜铃响完就安静了。你拿到手上，扫一扫，听听那头的人现在过得怎么样。刚刚故事里那个能让人走完归途的东西叫返乡机票，这是咱们这一关的信物。再往下唱的时候留点气，把最后两个字唱轻一些。

### 五条种子粮票寄语

1. 桥下有人收橹，桥上有人往回走。山塘街捎你一撮桂花。
2. 你要还没找到回家的票，坐稳了听这十秒。河面上的灯没灭。
3. 不问你从哪条路过来。碗腾出来了，接过时手别贴碗底。
4. 桂花浮在粥上，我用琴弹了一下水纹。寄到你那边还是暖的吗？
5. 今天我说到家了，你也可以晚一点报平安。山塘街等得起。
