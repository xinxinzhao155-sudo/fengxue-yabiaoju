# 大冰的小屋 · 风雪押镖局｜公共资源定稿

**当前采用「绢本青绿 · 马帮行旅」v1.4，更新于 2026-11-23。** 小程序、双屏互动和提案页面共用本目录的成品。后续新增物料，以这里收录的实物插画、24 px 图标和界面组件为对照。活动四城为丽江、济南、成都、拉萨。

双击 [物料总看台](./物料总看台.html) 可离线对照 9 张参考图、5 件主物料、9 组小图标（14 个状态文件）及 1 套界面组件。程序可读取 [资源清单](./资源清单.json)，其中的路径均相对于本目录，附有视框、状态入口和文件 SHA-256。本版保存在同目录的 `马帮行旅_v1.4_行旅工笔.zip`，解压后可独立打开看台。

## 画风与用色

[绢本青绿行旅图](./01_风格参考图/青绿山水_行旅驿站.png)和长沙、成都两幅城景是本版的用色、线条与设色参照。古甲图仍用于核对衣物的交领、绗线与扣件结构。

以石青 `#77919B` 层叠青黛 `#48636C`，施苔色 `#78816B` 和局部朱砂 `#A35F46`，旧金 `#BC955F` 仅绘小面积刻线。淡绢 `#E9D6AF` 留光，褐墨 `#524637` 勾形。衣褶、瓶肩、山脊和翼羽按体面收笔。主物料保留分色矢量细节；64 单位小图标以同套绢本行旅器物稿为准，驿舍以一檐两柱单独补绘，均为透明分色路径。小程序可直接取用 02_交互图标库/24px/ 下的轻量独立 SVG。24 px 另画简化线稿，可通过同一 SVG 的 `#compact` 调用，深色底可用 `#compact-night`；小稿也会随视口宽度自动切换。导航选中后出现双角印记；底栏预览与图鉴内的状态保持同步。看台并列展示大图及 24 px 实例，铜铃以音波和斜线区分开关。绢本设色色谱按六组展示行旅参考图的实景局部与对应 sRGB 色值。主物料与导航大稿以分色路径叠加可编辑勾线，勾线层标记为「勾线与分染」。主色、界面色与交互状态色均可点击复制；跨目录调用时可复用 base_style.css 中的 --fx- 变量。看台的「取用同款间色」可混合十二种基色与三种辅助色，用于还原细笔分色。

## 从其他文件夹调用

同一项目下，若页面位于与 `00_公共资源` 并列的文件夹第一层，可直接用下面的相对路径。更深的页面按实际层级增加 `../`。构建或发布小程序时，把用到的文件纳入该项目的静态资源目录，并将调用前缀指向打包后的路径。

```html
<link rel="stylesheet" href="../00_公共资源/04_界面组件与边框/base_style.css">
<img src="../00_公共资源/03_活动产品与周边/gift_jiuguan.svg" alt="风雪特调玻璃瓶">
<img src="../00_公共资源/02_交互图标库/nav_home_active.svg" width="24" height="24" alt="押镖主页，已选中">
<button type="button" class="fx-button" aria-pressed="false">接镖出发</button>
```

保持组件 CSS 与 SVG 同目录，样式表会自动引用 `#button`、`#button-highlight`、`#card`。接镖操作由业务页面处理，切换选中状态时同步更新 `aria-pressed`。故事卡使用 `.fx-story-card`，内部依次使用 `__title`、`__code`、`__body` 后缀；字号、宋体回退、焦点描边、按压位移和卡片内距均已写入组件 CSS。

根目录的 `theme.css` 和 `shared_data.js` 是早期页面样式与示例数据。定稿组件入口为上面的 `base_style.css`；四城名单以本规范及定稿文牒为准。音效预留在 `05_音效库`。
