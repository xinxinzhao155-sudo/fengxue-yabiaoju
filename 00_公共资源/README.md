# 大冰的小屋 · 风雪押镖局｜公共资源定稿

**当前采用「马帮行旅 · 古甲设色立绘」v1.0，定稿于 2026-11-20。** 小程序、双屏互动和提案页面共用本目录的成品。后续新增物料，以这里收录的实物插画、24 px 图标和界面组件为对照。活动四城为丽江、济南、成都、拉萨。

双击 [物料总看台](./物料总看台.html) 可离线对照 8 张参考图、5 件主物料、9 组小图标（14 个状态文件）及 1 套界面组件。程序可读取 [资源清单](./资源清单.json)，其中的路径均相对于本目录，附有视框、状态入口和文件 SHA-256。定稿副本保存在同目录的 `马帮行旅_v1.0_定稿.zip`，解压后可独立打开看台。

## 画风与用色

以[古甲武将立绘](./01_风格参考图/a8d0b7cba4badd31e26e2c8cf6c5d2bc.jpg)定衣料、甲片、旧铜与暖绒。以[青绿山门](./01_风格参考图/644ecd38ddf0ed520d50410c8de0763d.jpg)及同目录古建图定檐口、折角与排线。大图靠轮廓、遮挡和材质明暗建立层次。看台所列 sRGB 取样如下，成品里的过渡色随材质变化。

| 材质 | 受光或正色 | 背光或暗面 | 应用 |
|---|---|---|---|
| 朱漆 | `#8E3A28` | `#6E3123` | 衣缘、漆木与红色包边 |
| 旧铜 | `#B97742` | `#704329` | 铃唇、扣件、包角的窄亮边 |
| 黛青衣料 | `#264A50` | `#273430` | 旗面、衣襟和青布书脊 |
| 铁甲 | `#4E4442` | `#25201C` | 片甲弧面、叠压处聚墨 |
| 暖绒 | `#C7AD92` | `#AA8F71` | 毛尖断笔、绒根短影 |
| 旧绢 | `#DBD7CE` | `#DAD6CD` | 参考图留白、预览衬底 |

**运笔与构造。** 沿布褶走线，在折返、搭接和缝口加深墨色。铜面用窄亮边交代弧度，羽毛按羽轴分片，纸边轻弯，在装订处露出参差纤维。传统元素落在物件的构造上，如衣襟的右衽、燕尾旗的压边、册页的青布装订和方印形瓶塞。主视觉保留这些细节；导航尺寸优先保留外形和一处最醒目的物件特征。以定稿小屋为例，64 单位画布上屋檐外线约 1.9，次级线约 0.75–0.85，端点和转角圆收。

## 从其他文件夹调用

同一项目下，若页面位于与 `00_公共资源` 并列的文件夹第一层，可直接用下面的相对路径。更深的页面按实际层级增加 `../`。构建或发布小程序时，把用到的文件纳入该项目的静态资源目录，并将调用前缀指向打包后的路径。

```html
<link rel="stylesheet" href="../00_公共资源/04_界面组件与边框/base_style.css">
<img src="../00_公共资源/03_活动产品与周边/gift_jiuguan.svg" alt="风雪特调玻璃瓶">
<img src="../00_公共资源/02_交互图标库/nav_home_active.svg" width="24" height="24" alt="押镖主页，已选中">
<button type="button" class="fx-button" aria-pressed="false">接镖出发</button>
```

保持组件 CSS 与 SVG 同目录，样式表会自动引用 `#button`、`#button-highlight`、`#card`。接镖操作由业务页面处理，切换选中状态时同步更新 `aria-pressed`。故事卡使用 `.fx-story-card`，内部依次使用 `__title`、`__code`、`__body` 后缀；字号、宋体回退、焦点描边、按压位移和卡片内距均已写入组件 CSS。

根目录的 `theme.css` 和 `shared_data.js` 是早期页面样式与示例数据。定稿组件入口为上面的 `base_style.css`；四城名单以本规范及定稿文牒为准。音效预留在 `05_音效库`。
