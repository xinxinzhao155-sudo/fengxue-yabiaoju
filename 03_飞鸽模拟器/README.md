# 江湖飞鸽传书匣

《风雪押镖局 · 四城共熬一碗粥》3 号位。本地路演工作台模拟发镖分舵的客人手机、接镖分舵的吧台传书匣，以及自助撕、扫、贴的完整过程。

## 打开方式

双击 `index.html`，用 Chrome、Edge 或 Safari 打开。页面可直接用 `file://` 浏览，使用本地脚本、SVG 和图片。无需联网、启动服务器、安装依赖或授予摄像头权限。第一次点击附原声或发镖时，会按浏览器的音频播放规则启用 Web Audio。平板、手机可通过顶部页签切换三个视角。

关闭或刷新页面会清空本次演示的文牒、票夹、纸量与回执。声波码可在网页里点击模拟微信扫码，现场照使用四城预制场景图。核销码仅在演示里有效。

## 一分钟路演

1. 保持默认的「西安南门 → 苏州山塘街」，按「快捷演示 · 仅差一票」。苏州文牒先盖本城印，并贴入武汉与南昌两张演示样票；西安红枣留作最后一格。
2. 在手机端点「换一句」，再点「附上原声」试听西安扫弦，随后点「飞鸽传书」。看中间四个阶段依次点亮，约 1.5 秒时苏州铜铃响，约 2.9 秒时黄纸走完。
3. 点粮票锯齿线或下拉撕票。点票尾声波码听完十秒民谣，在同一浮层点「拍一张本城小屋现场照回传给 TA」。左屏会出现山塘街的回执。
4. 点「点点胶贴文牒」。红枣票落格后，福粥升起音符蒸汽，四城合奏，弹窗显示限时 10 秒的吧台核销码。
5. 有余裕时展开「硬件原理解剖镜」，展示钱箱脉冲、电磁铁、黄铜铃、走纸与店员零介入的路径。

## 自由演示

- 顶部选择互斥的发镖城与接镖城，或按交换键。距离按两城地标的示例坐标计算为近似直线距离。手机里选「江湖随机盲盒分舵」会在发出时从其余三城随机抽选。
- 各分舵独立保留纸量、余温粮票夹和文牒。后续出票会把上一张留在余温粮票夹，打开挂夹可调出历史粮票继续撕、扫、贴。同一接镖文牒每个异城只收一张，回执回到原发镖分舵。
- 「守夜自动吐票」每 15 秒尝试向当前接镖城寄一张票，再点一次即停。当前正在走纸、页面不可见或浮层打开时，该次定时触发会跳过。
- 「四城连发演练」依次投递四笔，每城发一张、收一张。结束后恢复原来选中的双城并播放合奏。
- 看到粮票后选 58 mm 或 80 mm，再点「打印粮票」。打印页只包含当前粮票。热敏打印机选对应纸宽、100% 比例并关闭页眉页脚；示例页长 115 mm。终端打印效果取决于机型与驱动的可打印区域。

## 未来接入公共资源

在相邻公共目录按下述约定准备文件后，把 `js/data-adapter.js` 顶部的 `const USE_PUBLIC_ASSETS = false;` 改为 `true`。图标、真实驻唱录音与全局主题会一起切换。资源路径集中在同一个适配层，可按以后确定的公共目录结构调整。

- **全局主题**位于 `../00_公共资源/theme.css`。它在本地主题之后载入，声明或映射 `css/theme-adapter.css` 里的语义变量即可接管颜色、材质等。
- **SVG 图标**位于 `../00_公共资源/02_交互图标库/`，使用下表中的精确文件名。个别 SVG 载入失败时会显示内置图。传书匣双态使用相同画幅，推荐沿用内置 `440 × 238` 视框及纸口锚点 `(196, 182)`，这样切态时铜铃和吐纸位置对齐。
- **真实录音**默认放在 `../00_公共资源/03_真实录音/`，各城在 `audioFile` 声明对应的十秒 MP3，当前约定为 `xian_nanmen.mp3`、`wuhan_wuchang.mp3`、`nanchang_wanshougong.mp3`、`suzhou_shantangjie.mp3`。单城试听、扫码优先使用录音，读不到时回退合成。硬件声与四城同步合奏继续使用 Web Audio，便于控制时序与合奏调性。
